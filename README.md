# 💸 Money Business — Financial Cash Transfer & Remittance Management

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A specialized ledger and cash reconciliation system for remittance distributors, retail money transfer agents, and local financial service shops.

---

## 🌟 Key Features

- **Agent Cash Balance Log**: Track opening and closing float for bKash, Nagad, Rocket, and Bank counters.
- **Customer Remittance Registry**: Record incoming and outgoing remittance payments with receiver NID details.
- **Daily Commission Calculator**: Automatic calculation of daily commissions earned from transactions.

---

## 🛠️ Technology Stack

- **Framework**: Next.js, React, Tailwind CSS

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/moneybusiness.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
